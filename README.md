# Emby 反代 Lite 版（Cloudflare Worker）

极简 Emby 反代方案：**只做反代播放，没有多余功能**，最适合想最快跑起来、只给朋友分享播放链接的场景。

- 存储只用 **Cloudflare KV**（免费、无需数据库）
- 一个文件、三步部署
- **管理面板就在域名根路径**：`https://你的域名` 打开即是面板
- 支持故障转移、强力防 403、图片缓存、HLS 切片重写、`/emby` 子路径自动适配

---

## 特性

| 功能 | 说明 |
|---|---|
| 根路径面板 | `https://你的域名` 直接是管理面板，无需记忆任何路径 |
| 基础反代 | `https://你的域名/节点路径/xxx` → 源站 |
| 故障转移 | 源站挂了自动切备用（多个源站用英文逗号分隔） |
| 强力防 403 | 节点模式选「强力代理」，自动伪装 Referer/Origin |
| 图片缓存 | 开启后静态图片走 Cloudflare 缓存，省源站流量 |
| HLS 重写 | M3U8 绝对/相对/协议相对切片全兼容，播放不花屏 |
| `/emby` 自适应 | 源站挂在 `/emby` 子路径也能自动回退，无需手填路径 |

## 部署步骤（约 3 分钟）

### 1. 创建 Worker

打开 [Cloudflare Dashboard](https://dash.cloudflare.com) → **Workers 和 Pages** → **创建 Worker** → 粘贴 `lite.js` 全部内容。

### 2. 修改顶部配置区

```js
const ADMIN_USER = "admin";        // 面板登录账号（字母数字）
const ADMIN_PASS = "你的密码";      // 面板登录密码（字母数字）
```

> ⚠️ 不改会怎样：部署后会直接返回 500 提示「部署配置未完成」，防止你带着占位符上线。

### 3. 绑定 KV 命名空间

- 侧边栏「设置」→「变量和机密」→「KV 命名空间绑定」
- 添加绑定：**变量名称必须是 `EMBY_KV`**，选择（或新建）一个 KV 命名空间
- **部署**，完成。

## 绑定自己的域名（白嫖 Cloudflare 加速）

默认用 `*.workers.dev` 访问速度一般；想用自己的域名走 CF 加速，按下面几步：

1. **Worker 详情 → 设置 → 域和路由**
2. 点击 **添加路由**，选择你已接入 Cloudflare 的域名并指定子域，把路由的 `*.你的域名/*` 改成 `自定义前缀.你的域名/*` 这种格式，例如：`emby.example.com/*`
3. 到 **Cloudflare 域名概览**，选择你刚添加到 Worker 的域名，点击 **DNS 记录**，添加一条 CNAME 记录：
   - **前缀**：填你刚刚自定义的前缀，例如 `emby`
   - **关闭小黄云**（仅 DNS，不开代理）
   - **目标**：填入 `saas.sin.fan`
   - 保存
4. 然后你就能通过这个域名（例如 `https://emby.example.com`）访问你的面板了

> 💡 面板在根路径：`https://emby.example.com` 直接打开即是管理面板；客户端地址为 `https://emby.example.com/line1`。

## 使用说明

1. 打开 `https://你的域名`（根路径就是面板）→ 用配置区的账号密码登录
2. 点底部「添加」→ 填：
   - **专属后缀**：如 `line1`（客户端访问路径）
   - **节点名称**：随便起
   - **源站地址**：`http://源站IP:端口` 或 `https://域名`，多个用逗号分隔
3. 保存后，把这条链接发给朋友或者自己使用：

```
https://你的域名/line1
```

朋友/自己在 SenPlayer / 影视类 App 里填这个地址即可播放（地址会 302 到源站登录页，登录后正常看）。

## 常见问题

**Q：访问域名提示 500「部署配置未完成」**
→ 顶部 `ADMIN_USER` / `ADMIN_PASS` 还是占位符，改掉再部署。

**Q：提示「未绑定 KV 命名空间 EMBY_KV」**
→ Worker 设置里没绑定 KV，变量名必须严格是 `EMBY_KV`。

**Q：播放卡顿/花屏**
→ 节点编辑里开启「图片缓存加速」；HLS 重写已默认开启。

**Q：首页能打开，播放接口 404**
→ 源站挂在 `/emby` 子路径？本版已自动适配，无需手动改源站地址。确认源站地址填的是裸域名/IP（不带 /emby 路径）。

**Q：想改面板密码**
→ 面板「设置」→「安全中心」改账号密码（存 KV，重启不丢）。
